Legend

Row state (left border + tint)

  • Green — outlet is energized (on)
  • Grey — outlet is de-energized (off)
  • Amber — transitioning (pending power-on delay / reboot in progress)
  • Red — device reports a fault on this outlet
  • Blue — WOL mode, host is awake (action label becomes SLEEP)
  • Indigo — WOL mode, host is sleeping (action label becomes WAKE)

Columns

#
Physical outlet number (1–8). Outlet 1 is the C19 (high-current) socket.
Name
User-settable outlet label stored on the device itself. Click to edit. 1–16 chars, only letters, digits, underscore and space.
V
Voltage at the outlet. ~225 V when on, 0.00 when off. Use it to confirm a shutoff actually de-energized the outlet.
A
Current draw in amps. Shows what the connected load is pulling right now.
W
Instantaneous power consumption. Roughly V × A with power-factor correction. What the load costs you per hour ÷ 1000.
₪/mo
Projected monthly spend if the current W stays constant: W × 730 / 1000 × rate. Rate comes from ELECTRICITY_RATE_ILS_PER_KWH (default 0.61).

Shutdown modes

KILL
kill-the-power — default. Off cuts power immediately; on restores it immediately.
WOL
wake-on-lan — the outlet is never actually powered off. The on command sends a Wake-on-LAN magic packet to the outlet's MAC; the off command asks ATEN's Safe-Shutdown agent on the host to shut down cleanly into standby. Useless unless that agent is installed on the connected machine. The on/off state we read tracks the host's awake/sleep, not the outlet's power. Buttons read WAKE / SLEEP and rows tint blue/indigo to flag this.
AC-BACK
after-ac-back — niche. Off command does not cut power immediately; it defers the shutdown until the next AC power event. This is not the "restore previous state on power loss" setting — that one lives in the PDU's firmware Power Recovery option, configurable only via the web UI.

How to use

  • Click a socket in the chassis above to toggle it on/off.
  • Click an outlet name (card or table) to rename the outlet on the device.
  • Use the row button for an explicit TURN ON / OFF action.
  • Telemetry refreshes every 2 s; it pauses while you have a name field focused so edits aren't lost.
